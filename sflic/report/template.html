License and user data were read once, read-only, through the Salesforce APIs and stored as a timestamped snapshot with a SHA-256 hash for every data file. The analysis runs offline against that snapshot.

Limitations

  • Dormancy uses each user's last login date. A user who logs in but does not use a product (for example holds a CPQ seat and never opens CPQ) is not detected.
  • Licenses with no seat count (total 0, or a site-wide managed package) are not listed.
  • Feature licenses set on the user record (Marketing User, Service Cloud User, Knowledge User and similar) are not assessed.
  • Prices are the ones in settings.yaml. Contract terms, minimum quantities and bundled licenses are not known to the tool.
